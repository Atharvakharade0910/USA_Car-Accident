# USA Car Accident Severity Prediction

This project is a machine learning-based web application that predicts the severity of car accidents in the USA. The model is trained using accident-related data such as weather conditions, visibility, temperature, humidity, wind speed, location, time, and road/environmental factors.

The project uses Python for data preprocessing, analysis, and machine learning model development. A Streamlit frontend is created to provide a simple and interactive user interface where users can enter accident details and get the predicted accident severity.

## Objective

The objective of this project is to analyze USA car accident data and build a machine learning model that can predict accident severity based on different accident and environmental features.

## Features

- Data cleaning and preprocessing
- Exploratory Data Analysis
- Feature selection and encoding
- Machine learning model training
- Accident severity prediction
- Model performance evaluation
- Interactive Streamlit frontend
- User input-based prediction system

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Machine Learning

## Machine Learning Models Used

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost / LightGBM

## Frontend

The frontend is built using Streamlit. It allows users to enter accident-related details and predicts the severity level of the accident using the trained machine learning model.

## Output

The system predicts the accident severity level based on the given input features.
